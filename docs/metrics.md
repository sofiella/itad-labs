# ЛР № 5. Расчёт метрик Seoul Bike Sharing Demand

## Данные

Как меняется связь температуры со спросом на велопрокат в зависимости от времени суток?

Источник данных для расчёта: витрина из ЛР № 4 `s3://mart/seoul-bike-sharing-demand/source_ingested_on=2026-09-30/hourly_rentals.parquet`. Снимок загрузки от 30.09.2026 содержит наблюдения с 01.12.2017 по 30.11.2018. Одна строка витрины соответствует одному часу конкретной даты.

В витрине 8760 строк. В расчёты вошли 8465 часов со статусом `Yes`. Остальные 295 часов имеют статус `No` и исключены, поскольку в эти часы прокат не работал. Это те же строки, которые отмечены флагом качества в ЛР № 3. Для разбивки по сезонам использован месяц даты, так как столбца сезона в витрине нет. К зиме отнесены декабрь, январь и февраль. Весна длится с марта по май, лето с июня по август, осень с сентября по ноябрь. Это то же правило, по которому проверялся сезон в ЛР № 3.

## Метрики

| Метрика | Как рассчитывается | Какие значения входят |
|---|---|---|
| Средний почасовой спрос | Сумма числа аренд, делённая на число часов с известным числом аренд. Результат показывает, сколько велосипедов арендовали в среднем за час. | Известные значения числа аренд за часы работы проката. Ноль, если он есть в рабочий час, входит в расчёт. |
| Корреляция температуры и спроса | Коэффициент Пирсона между температурой в градусах Цельсия и числом аренд за час. Он показывает направление и силу линейной связи. | Часы работы проката, для которых известны оба значения. |

Для каждой группы отдельно указаны число наблюдений, число значений для среднего и число пар для корреляции. Общий итог рассчитан непосредственно по 8465 наблюдениям, а не по средним или коэффициентам отдельных групп. Средний спрос составил 729,16 аренды в час, общая корреляция равна 0,5627.

В основной группировке оконная сумма считает число наблюдений по всем часам суток. Доля часа показывает, какой процент всех рабочих наблюдений приходится на этот час. Это доля наблюдений, а не доля аренд. Если знаменатель равен нулю, доля не вычисляется.

## Таблицы для ЛР № 7

Все три результата находятся во временных таблицах DuckDB. Отдельные файлы с данными не создаются.

| Таблица | Что означает одна строка | Что есть в таблице и зачем она нужна |
|---|---|---|
| `metrics_by_hour` | Один час суток, например 08:00 | Средний спрос, корреляция, размеры выборок для обеих метрик и доля наблюдений. Подходит для сравнения показателей между часами. Всего 24 строки. |
| `metrics_by_hour_season` | Один час суток в одном сезоне | Те же две метрики и размеры выборок. Позволяет сравнить связь при одном и том же часе суток внутри разных сезонов. Всего 96 строк. |
| `temperature_rental_pairs` | Один рабочий час конкретной даты | Дата, час, сезон, температура и число аренд. В выборку вошли все рабочие часы, в которых известны оба числовых значения. По этим записям можно построить диаграмму рассеяния без группировки. Всего 8465 строк. |

## Проверки

| Что проверялось | Ожидание | Результат |
|---|---|---|
| Число наблюдений в группировках | Суммы по часам и по сочетаниям часа и сезона совпадают с общим итогом. | Во всех трёх случаях 8465 наблюдений. Получено 24 группы по часам и 96 по часам и сезонам. |
| Сумма долей по часам | Сумма долей без предварительного округления равна 100 %. | 100 % с учётом точности вычислений. |
| Число значений для среднего | Число значений, использованных для среднего, совпадает с отдельным подсчётом рабочих часов с известным числом аренд. | В обоих расчётах 8465 значений. |
| Число полных пар | Число пар в корреляции и число строк в отдельной выборке совпадают с подсчётом рабочих часов, где известны оба значения. | Во всех трёх случаях 8465 пар. |

## Вывод

По всем сезонам вместе связь температуры со спросом в 00:00 была сильнее, чем в 08:00: корреляция составила 0,7914 на 352 наблюдениях и 0,4627 на 353 наблюдениях соответственно. При этом средний спрос утром был выше: 1050,23 аренды в 08:00 против 561,46 в 00:00. Сезонный срез показывает, что общая положительная связь не обязательно сохраняется внутри сезона. Например, в 14:00 весной корреляция равна 0,6198 (90 наблюдений), а летом -0,2279 (92 наблюдения). В группах по часу и сезону от 80 до 92 наблюдений. Данные охватывают один год, а расчёты не учитывают осадки и другие факторы. По корреляции нельзя установить, что различие вызвано температурой.
